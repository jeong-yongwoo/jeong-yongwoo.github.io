# 포트폴리오

정용우의 포트폴리오 사이트입니다.

**https://jeong-yongwoo.github.io/**

## 파일 안내

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 본문 — 내용은 여기서 고칩니다 |
| `style.css` | 색·글씨·여백 등 디자인 |
| `main.js` | 스크롤 효과 |
| `CONTENT.md` | 사이트에 들어간 원본 내용 (여기 먼저 고치고 index.html에 반영) |
| `images/` | 프로필 사진 등 이미지 |

수정 후 GitHub에 push 하면 1~2분 뒤 사이트에 반영됩니다.
